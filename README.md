# Site de Currículo Pessoal — HTML5 + CSS3

## Estrutura
- index.html — Home
- about.html — Sobre/Currículo
- portfolio.html — Projetos (CSS Grid)
- hobbies.html — Hobbies (Flexbox)
- contact.html — Contacto e validação HTML5
- css/style.css — CSS externo
- images/ — imagens SVG de exemplo
- media/ — coloque aqui o seu vídeo e áudio

## Como abrir no VS Code
1. Extraia a pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador.
4. Substitua `Nome Apelido`, email, telefone, links e imagens pelos seus dados.

## Multimédia
A Home já possui as tags `<video>` e `<audio>`. Para funcionarem, coloque:
- `media/apresentacao.mp4`
- `media/apresentacao.mp3`

Os SVG em `images/` são placeholders leves e podem ser substituídos pelas suas fotografias, certificados e capturas de ecrã.
